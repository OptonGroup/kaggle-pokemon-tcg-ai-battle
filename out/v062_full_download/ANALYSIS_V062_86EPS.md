## Системные дефекты (кросс-провалидированы)

### БАГ-1 (критический): `_promotion_guard` теряет bench-слот 0
`main.py:585`: `idx = int(o.get("index") or -1)` — Python-фолси: `0 or -1 == -1`, опция
скамейки с index=0 всегда пропускается. Guard обслуживает И принудительный промоушен (ctx 4),
И добровольный switch (ctx 3) → здоровый Grimmsnarl ex в слоте 0 невидим, в актив идёт
Munkidori/Impidimp. **Воспроизведено детерминированно** на синтетическом obs (guard вернул [1]
вместо [0]). Все остальные guard'ы используют корректный паттерн `if ... is not None else -1`
(проверено грепом). Прямо стоил ~4-5 игр: 87387027, 87346991, 87350515, 87356940, 87340829.

### БАГ-2: приоритет промоушена игнорирует энергию
`_promo_priority` = (tier, hp): заряженная копия (5 энергий) проигрывает tie-break здоровой
пустой → в актив идёт Grimmsnarl без энергии, 3 хода не атакует и не ретритится (87346272).

### ДЕФЕКТ-3: поиск тащит мёртвые копии Grimmsnarl ex
`score_to_hand`: Spikemuth/Dawn/Night Stretcher/generic дают 648 безусловный топ (20000/18000),
даже когда эволюционной базы нет и копия уже в руке → 3 мёртвых ex в руке, скамейка 0-1 всю
игру, проигрыши через bench-depletion/"no Pokemon" (87349861, 87352866, 87353969, 87348679).
Wave3-фикс v062 (динамические тиры) покрыл только Impidimp/Munkidori, но не 648/647.

### ДЕФЕКТ-4: нет защитного свопа на матчпойнте
Ретрит фиксированно -100; повреждённый 2-призовый Grimmsnarl ex остаётся в активе, когда его
KO отдаёт сопернику ПОСЛЕДНИЕ призы, при здоровой замене на скамейке (87346911, 87356281,
87344391, 87360358). Экспертные данные («ретрит не HP-триггерится») не противоречат узкому
эндшпильному правилу: цена — сама игра.

### ДЕФЕКТ-5: застрявший небоевой актив
Активный Froslass/Snorunt/Munkidori с 0 энергии не может ни атаковать, ни оплатить ретрит;
энергия ему не крепится (attach_target_score −2000 для 104/860) → заряженные Grimmsnarl
гниют на скамейке 15+ ходов (87342635, 87362429), Freezing Shroud добивает своих же.

### ДЕФЕКТ-6: зависания на повторяющемся select
Идентичный select повторяется до лимита шагов (prize-take loop 87341448, stalled selection
87339069, switch-loop 87355692) — агент отвечает одинаково, движок не продвигается, эпизод
обрывается/присуждается по призам. Нужен loop-breaker.

### ДЕФЕКТ-7: deck-out в стенах
В безнадёжном Rock Inn-матчапе агент продолжает максимизировать добор → high-speed deck-out
за 8 ходов (87344398), 45→0 карт.
