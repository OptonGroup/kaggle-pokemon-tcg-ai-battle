## 1. Арифметика цели: 60% — это смена класса пилота, а не заплатки

Расчёт по матчап-вектору deeper-линии (782 игры) и составу бэндов (полные таблицы —
сырьё воркфлоу, агент-арифметик):

**(а) Модель не сходится, и это само по себе результат.** Ожидаемый WR бэнда из
глобального матчап-вектора минус факт: −3.7пп (600-е) → +4.3 (700-е) → +8.2 (800-е)
→ **+16.3пп (900-е)**. Те же архетипы наверху играют существенно сильнее — эффект
любой заплатки, посчитанный по глобальному вектору, наверху надо дисконтировать.

**(б) Точечные заплатки не дают 60% нигде.** Сценарий «mirror 43→55, archaludon
32→50, dragapult 36→50»: 700-е → 46.5%, 800-е → 43.1%, 900-е → 37.5%. Дефицит
13–22пп. Даже ВСЕ именованные матчапы до 60% не закрывают ни один бэнд: треть массы
800-999 — «прочие» (.36–.37), недоступные заплаткам по определению.

**(в) Требуемый глобальный сдвиг: +22.6пп (800-е), +26.7пп (900-е).** Комбинация
«глобально +5пп И mirror до 60%» оставляет дефицит 14–17.5пп. Реальная формула цели:
**глобальный подъём класса решений +15–20пп И mirror ≈70%+**.

**(г) Existence proof ровно такого подъёма существует и локализован.** Топы играют
НАШУ деку (835/1273 = 66% их игр): суммарно 60.6% (506-329) против наших 52.4%
(z=3.2, p=0.0014); Luca — 63% (357 игр, лист −1 карта от нашего), Dominic Peel —
64% (88 игр); зеркало у них 58% против наших 50%. Метод — детерминированные
эвристики / сошедшийся BC, **без search**. Разрыв +5…+15пп размазан по ВСЕМ
матчапам — ровно та сигнатура «глобального сдвига», которую требует (в).

**Вывод, определяющий весь план: агент с WR 60% = пилот класса эталонов
(Luca/Peel) на их же деке. Единственный трек с existence proof цели — 2B
(BC-гибрид на корпусе эталонов). Всё остальное — страховки и добивки.**

### 2.1 Состав агента

1. **Дека**: Grimmsnarl toolbox линии v0NN (лист эталонный; Luca = −1 карта от нашего).
2. **BC-приоритизатор**: sklearn-деревья, **раздельные модели по группам
   sel_context** (паттерн роутинга tetsutani: main / c7 / low / mid / easy — порт
   схемы, не кода), экспорт чистыми списками как `export_gbm` (live-safety: без
   torch/numpy-ABI, `project_kaggle_live_safety`).
3. **Guard-слои вне сети** (фиксы известных провалов BC): retreat-guard
   (minority-class collapse: у эксперта retreat 2.8% при легальности 35.7%),
   promotion-guard (урок v075 Impidimp), KO/legality-guard. База — форк
   `submissions/v076_final`: проверенные правила остаются fallback-политикой.
4. **Эндшпиль**: таблица PRIZE_VALUES (~150 записей card_id→2|3, порт данных из
   `tetsutani/extracted/tactical_guard.py:13`) — форсаж размена, когда prize-value
   актива оппонента ≥ его оставшихся призов.
5. **Mirror-знания** — приоритет №1 внутри корпуса: зеркало = 40–48% игр
   топ-бэнда, поэтому корпус зеркалом богат; экспертное зеркало содержит явные
   механики (Poffin-дисциплина, ротация заряженного Grimmsnarl, «never END while
   legal attack» — `experts/mirror/manual_policy.py:1088`). Прямые END-гварды у нас
   исторически роняли archaludon → любые такие правила вводить только через
   mirror-контекст и мерить mirror-страту отдельно.
6. **Опционально, 2-й круг**: лёгкий 2-ply поиск с анти-шумовым порогом
   «переопределяй эвристику только при перевесе ≥ пол-приза» (порт схемы jazivxt:
   N_DET×K_OPP=3×3, ~0.8с/решение) — только если BC-ядро прошло гейт.

### 2.2 Приёмка

- **Офлайн (дёшево, без стенда)**: top-1 agreement на held-out решениях эталона.
  Порог go на гейт: **≥0.75 overall И ≥0.65 attack** (пилот v074: 0.587/0.54;
  ориентир достижимости: coalition-подмодель tetsutani = 0.886 offline — с оговоркой,
  что это узкая подвыборка её включения, не top-1 всего пилота на всех контекстах).
  0.70–0.75 — один разведочный гейт-слот без реранов; <0.70 — не шипится.
- **Гейт**: против ДВУХ баз — `v076_final` (та же дека → чистый замер класса
  пилота) и `gatecfg_deeper_p0p1` (текущий live); пул + перевзвешивание по полю;
  отдельные страты: mirror (vs external_tetsutani_grimmsnarl + holdout
  prvsiyan_grimmsnarl_hybrid) и Crustle-стена (эталон 53%, линия v0NN 30%,
  **порог ≥45%**). Ожидаемый эффект при удаче двузначный — единственный трек,
  чей эффект вообще детектируем нашим MDE (§6.1).
- **Риски**: механизм «клон ≤ автор» подтверждён 5 раз (BC-потолок 800–930);
  контраргумент — впервые авторы корпуса сами 63–64% / μ1136–1158. Дыры корпуса:
  lucario 3 игры, archaludon 5 игр (при массе .26/.17 бэнда 700-799) — ловить
  holdout-оппонентами, откат при z<−1.0. Rogue-уязвимость NN (v024: 20% vs
  незнакомые деки) — страхуется fallback-правилами v076_final.

Трудоёмкость: датасет 4–6ч (CPU-парсинг, совместим с идущим R4) + фичи 4–8ч +
обучение 4–6ч + сборка гибрида 6–10ч + офлайн-замер 1–2ч = **критический путь
19–32ч последовательной работы (стадии зависят друг от друга), делегируется
sonnet-субагентам**; стенд нужен только на гейты. Верх диапазона в развилку
вечера 08-11 не помещается — обработка отставания заложена в календарь §5.

  archaludon .239, mirror .127 — для T1/T2-B перевзвесить в сторону mirror, §4)
  ×2 рерана: SE≈1.9пп → **порог значимости ≈+4.8пп, 80% мощности ≈+6.4пп по полю**.
- Следствие-правило: **кандидат с честным ожиданием <+5пп по полю не получает
  standalone гейт-слота** — только офлайн-приёмка и/или пассажиром в паке.
  Гейт-слотов до заморозки всего 6–8 (полный шип-цикл ≈ 5–7ч стенда).

### 6.2 Шип-бар (все пункты, MEASUREMENT_POLICY)

Стратифицированный расчёт (не пулинг) + контрольная страта ≈0 + ≥2 полных рерана +
p<0.01 + holdout из независимых чужих реализаций (z≥−1.0 на каждом non-off-target) +
перевзвешивание по свежему полю + ожидаемый вклад в общий WR заявлен ДО заливки и
>+2пп. Ниже бара — не сабмитить: замена tracked-слота на шум хуже статус-кво.

### 6.3 Гигиена стенда (2 инцидента за сутки — проверять каждый запуск)

## 7. Честная сводка вероятностей

| Исход к заморозке 08-13/14 | P | Комментарий |
|---|---|---|
| Локальный WR ≥60% (топ-30) | **2–5%** | требует, чтобы 2B v1 сразу взял класс эталона; исторически BC v1 берёт ~40% скилла автора |
| 52–55% (μ≈900–1000) | **20–30%** | нужен ≥1 честный PASS (T1 или T2-B); единственный исторический прецедент прохождения порога — бюджет поиска +5.8пп |
| Сохранить статус-кво 47–48% | **>90%** | при дисциплине отката и запрете правок в последние 48ч |

**Переформулировка цели без обмана себя: «агент с WR 60%» — это архитектура T1
(existence proof: Luca 63%, Peel 64%, наша дека), и она строится сейчас; но её
доводка до 60% — процесс с итерациями по fidelity, которых до заморозки помещается
одна-две. К заморозке шипуется лучшая версия, прошедшая бар §6.2; асимптота 60%
добивается итерациями в окне Strategy-трека / после дедлайна.** Главный риск плана —
не «не вырасти», а потерять 48%: любой сабмит без полного бара запрещён.
