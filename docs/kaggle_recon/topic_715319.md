## Key Takeaways for Our Project

1. **Meta Kaggle dataset does NOT contain this competition's episode results** — contrary to what one might expect from past simulation competitions. Our episode data must be obtained another way.
2. **Internal API endpoint exists**: `https://www.kaggle.com/api/i/competitions.EpisodeService/GetEpisode` — takes an `episode_id` and returns episode data (agent_ids, results). This is a per-episode fetch, not a listing endpoint. Useful if we already know episode IDs (we do: `kaggle competitions episodes <SUB_ID>` gives us episode IDs per submission).
3. **No known way to enumerate ALL episode_ids** across the whole leaderboard — this was an open, unanswered question as of 2026-06-28. We rely on the `kaggle competitions episodes <SUB_ID>` CLI (which lists episodes per our submission) to scope what we can download.
