updated simulator expected to be released soon.

### Message — shige (organizer) (2026-06-30 06:25, +1)
**Resolution:** references simulator update discussion **716045**
(https://www.kaggle.com/competitions/pokemon-tcg-ai-battle/discussion/716045).
With this update, even if an agent enters an infinite loop or repeatedly performs rapid
non-progressing actions, the match should no longer end in a draw due to the previous step
limit. Instead, the **step limit has been increased** so the agent is expected to eventually
run out of its allotted time, and the player whose agent caused the loop will **lose by timeout**.
In a real PTCG match this would be a judge ruling; in automated simulation there is no human
judge, so they handle it by increasing the step limit and letting the time limit resolve it.
**NOT retroactive** — already-played matches are unchanged; only post-update matches follow
the new logic.
