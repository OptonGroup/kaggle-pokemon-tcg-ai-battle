What it is: a live dashboard + open JSON API for the ladder meta.
- Site: https://ptcg-ladder-meta.vercel.app , API: /api (open, CORS, Swagger at /api-docs)
- Video: https://youtu.be/sLpVoRvqT7U

The honest caveat first: this is the OBSERVED public surface — the host's daily TOP-episode sample. NOT the full ladder, NOT the hidden eval distribution. Sample sizes + Wilson CIs shown, thin data faded not hidden.

In it (6 days so far):
- Meta over time — prevalence, diversity, per-tier composition, churn
- Win-rate matrices — archetype-vs-archetype + team-vs-team, with n + CIs
- Per-team pages — WR trajectory, deck-version history, matchups, VISUAL decks (card images), tier staying-power
- Deck vs agent — your archetype's WR vs the field average for the SAME archetype, so you can tell empirically whether it's your deck or your agent
- Open API + Swagger docs — build on it

Corrections are welcome, if a number looks off vs your own decode, tell me, and I'll fix it.

Credit where it's due, this stands on a lot of community work:
