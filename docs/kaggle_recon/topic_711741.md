The evaluation is not based on a single match only. Since submissions continue to play multiple matches over the evaluation period, targeting one specific opponent or one short-lived metagame should not be enough on its own. Strong agents will need to perform consistently across repeated matches and different opponents.
For that reason, our expectation remains that each submitted agent uses a single deck consistently.
