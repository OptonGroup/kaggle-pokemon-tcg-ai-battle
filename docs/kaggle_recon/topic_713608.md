### 1. Problem Setup
- `cabt` engine interface: `agent(obs) -> list[int]`. Engine enumerates every legal play in `obs["select"]["option"]`; agent returns list of **indices** into that menu. You never construct an action; you rank/pick from a pre-generated list.
- Naive "build an attack/attach action" modeling had to be scrapped entirely.
- **Engine enumerates options in strong best→worst order.** Just returning `[0]` ("B1") beats random ~88–90%, a difficult local optimum to escape. A naive type-priority reorder of the menu LOST to B1 (3.3% vs first-index).
- **No seed hook.** Compiled engine's `BattleStart` takes only the 120 card IDs; no RNG seed exposed to Python. Every evaluation is independent-sample → significant variance problem.

### 3. Everything Tried and What Each Ceiling Taught

**3.1 Pre-transformer plateau (~9 methods, same ceiling).** Against Alakazam "Powerful Hand" deck:

| Method | Result vs B1 mirror | Lesson |
|---|---|---|
| 1-ply hand-crafted search | ~40% | ≤ B1 |
| 2-ply expectimax | ~50% | ≤ B1 |
| ISMCTS / AlphaZero-lite | 42.5% → 50% | Parity, never past |
| MLP self-play | ~52–67% | Feature ceiling |
| FSP pool (vs checkpoints) | 46.5% vs B1 | Worse than mirror self-play |
| Demo-RL (POfD-style) | Degrades | Representation wall |
| Static heuristic reorders | 2–20% | Native order too strong |
| ~10 hand-built decks | All < sample deck | Deck was the lever, not the pilot |

Every method plateaued, never robustly cleared B1. Failures were NOT capacity failures (256-wide MLP did no better than 64-wide) — they were **representation failures**: none encoded *which card* an option was, only type/damage. Network couldn't see card synergies.

Lever that broke through: **card-embedding multi-head transformer** (DMODEL=64, NHEAD=4, NLAYERS=2) where each option token = role one-hot + **per-card identity one-hot over full card vocabulary** + 15-dim scalar block. Card identity is the lever nine prior methods lacked. Transformer reached **73–74% vs B1 mirror** (revalidated at 400+ games) — first architecture to break the ~68.5% feature ceiling.

**3.2 Beam search: +11.3pp on weak heuristic, −15pp on strong one.** Replicated MultiPly agent's deterministic beam search (width=3, depth≤4, 1.5s budget):
- Alakazam heuristic (10.7% META) + beam → 22.0% META = **+11.3pp** (N=1,200, z≈5.7, confirmed at N=2,988 as 22.6%).
- Same beam on StarmiePolicy (54.0% META) → 38.6% META = **−15.4pp** (z≈7).
- Beam's crude leaf eval (prize_diff×10000 + energy×120 + hp terms) overrides Starmie's nuanced tempo play with greedy prize-grabbing. **Beam value inversely proportional to base-policy quality.** Wrap weak heuristics; leave strong ones alone.
- Latency ~8.6ms per MAIN decision. Kaggle budget is NOT the bottleneck.

**3.3 Imitation (BC/DAgger) plateaus below the teacher.** 8 DAgger iterations (400 DAgger + 100 anchor rollout games/iter, 64d transformer, teacher = AlakazamPolicy heuristic):

| Iter | Clone accuracy | H2H vs heuristic |
|---|---|---|
| 1 | 96.6% | 33.3% |
| 3 | 98.2% | 41.0% |
| 4 | **99.0%** | **28.0%** (OVERFIT — highest clone, worst H2H) |
| 5 | 96.4% | **41.3%** (best checkpoint) |
| 7 | 96.2% | 33.3% (declining) |

Plateau ~41% H2H; teacher wins 59-41. Iter 4 = textbook covariate-shift inversion (clone accuracy peaks when H2H collapses). Reproduced independently (iter 4: 28.7% in run 2). **Pure imitation cannot pass a heuristic teacher.** Need search on top, or RL self-play super-teacher trajectories. Search won (+11.3pp for Alakazam). RL did not produce measurable gain.

**3.4 RL plateau is a measurement limit, not algorithmic.** Privileged critic probe (logistic regression, n=6,211 self-play games):
- NN value head AUC: **0.61**
- 10-feature linear model on PUBLIC board state: AUC **0.818** (0.69 even on turns 1–4)
- Adding opponent's hidden hand: AUC **0.825** — delta **+0.007**

Outcome is NOT irreducibly noisy; hidden info is NOT the bottleneck; trivial linear probe nails signal the 64d value head underfit in training.
Substituted AUC-0.82 linear board critic as GAE baseline (`engine/board_critic.py`). vsR8 climbed 12%→18–20% then flatlined while held-out hard score eroded. 12→18 jump indistinguishable from noise at N=120 (±16pp). Verified-good baseline couldn't be shown to help — RL evaluator sits below its own noise floor.

Overfit-one-batch probe (`tests/probe_value_head.py`): 64d HL-Gauss value head on 64 synthetic boards under 3 signal types — all converged to **correlation 1.000**. Head can represent any board signal; 0.61 is not capacity/broken readout — it's **sparse, terminal-only self-play return targets evaluated through a noisy evaluator.**

Three independent probes converge: **bottleneck is data and measurement, not network/algorithm.** Until paired low-variance evaluator (N≥500, fixed decks, ideally common random numbers — which engine doesn't expose), no RL A/B is interpretable.

**3.5 Forensic loss-analysis trap.** 40 losing games → LLM analyzed. Correctly identified bench-out losses (15/40), surfaced 3 fixes: retreat low-HP active to deny prize, never attack for 0 damage when setup play exists, don't evolve only basic with empty bench. Implemented as guards, paired A/B (n=250/matchup):

| Matchup | Live guards | + 3 forensic guards | Δ | p |
|---|---|---|---|---|
| Mirror | 59.2% | 51.6% | −7.6 | 0.07 |
| TopBot | 64.0% | 52.4% | −11.6 | **0.012** |
| Anti-Crustle | 33.2% | 29.6% | −3.6 | 0.40 |
| **Pooled** | **52.1%** | **44.5%** | **−7.6** | **0.003** |

"Fixes" made agent significantly worse. **Survivorship bias:** reading only losses makes "stay in at 30 HP and attack" look like a mistake — losing traces hide every game won by grabbing a prize before dying. Policy's instinct is correct *on average*. Would have shipped ~7.6pp regression if trusted the narrative without A/B.

### 4. Eval Discipline (learned the expensive way)
Three eval failures:
1. **Short-eval inflation.** "77%" training metric at 200 games → 67% at 400 games. 128-dim "big net" hit 74% at 200 games, 66.8% at 400 games. Rule: revalidate at ≥400 games before trusting.
2. **Hill-climbing below the noise floor.** Hill-climbed 68 heuristic config weights for Alakazam; "best" went 0.786→0.861→0.921. Re-evaluated IDENTICAL config byte-for-byte (`CURRENT` vs `R8`) at 2,000 games: **0.8665 vs 0.8802 — 1.37pp gap from pure sampling noise.** Hill-climber accept threshold 0.5pp. Every "improvement" from R5 onward was reading noise. Honest Alakazam WR ~0.88, not 0.92.
3. **No Common Random Numbers.** Engine exposes no seed hook → every A/B independent-sample → forces sequential testing (SPRT-style) and larger N. Asks if anyone has CRN working.
