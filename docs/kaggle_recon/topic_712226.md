## Message 1 (original report) — 2026-06-22 16:10:21 UTC

> Hi everyone and organizers,
>
> I would like to report a potential bug in the CABT game engine regarding energy discard mechanics.
>
> **[Issue Description]** When using Greninja ex's "Mirage Barrage", the attack cost requires discarding 2 units of energy. However, when "Ignition Energy", which provides 3 Fighting energies, is attached, discarding just this single card should satisfy the 2-energy requirement.
>
> **[Current Behavior]** The engine's `obs.current.selection` enforces `minCount: 2`. If our agent selects only the Ignition Energy (submitting an array of length 1, e.g. `[idx]`), the engine crashes and throws an `err=4` (invalid selection) IndexError. Attempting to submit the same index twice (e.g. `[idx, idx]`) also results in `err=4`.
>
> **[Consequence]** Because the engine strictly requires an array of at least 2 distinct indices, players are forced to discard an extra energy card (e.g. a Water Energy) alongside the Ignition Energy, which puts them at an unfair disadvantage.
>
> Could the engine be updated to evaluate the provided energy value of the selected cards rather than strictly enforcing `minCount: 2` based on card count?
>
> Thank you!
